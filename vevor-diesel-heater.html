🔥 Vevor Diesel Heater

Så byggde vi en komplett fjärrstyrning med ESP32-S3 — webbpanel, schemaläggning med veckodagar, moln via MQTT, trådlösa uppdateringar — utan att tappa mobilappen.

ESP32-S3 Bluetooth LE Vevor Heater5905 MQTT ESPAsyncWebServer OTA GitHub Pages

Vad resultatet blev

  • Webbpanel hemma — temp, batteri, start/stopp, temperatur 8–36 °C, effektnivå, scheman, direkt mot kortet på WiFi.
  • Molnpanel — samma funktioner var som helst i världen, via publik MQTT-broker + GitHub Pages.
  • Schemaläggning — upp till 8 scheman med veckodagar och exakta tider, över-midnatt-fönster tillåtet (t.ex. 22:00→06:15). Sparas i flashminnet och överlever strömavbrott.
  • "Släpp Bluetooth" — knappen kopplar ifrån i N minuter så AirHeaterPro-appen kan använda värmaren; kortet återansluter självt.
  • OTA — alla senare uppdateringar sker trådlöst från webbsidan, aldrig mer USB.

2. Arkitekturen

[Telefon-app]--(BLE, vid behov)---[Värmaren]
                                      |
[ESP32-S3]----(BLE, alltid på)--------+
    |
    +--(WiFi hemma)--> Webbpanel + REST-API + schemamotor (flashminne)
    +--(MQTT)--------> Publik broker --> Moln-webbsida var som helst
Principen: ESP32:n äger Bluetooth-kopplingen dygnet runt och översätter kommandon från webb/moln till värmarens råa protokoll. Appen får plats genom "släpp Bluetooth"-fönstret. Schemana triggas av kortets NTP-synkade klocka, så de går på minuten även utan mobil eller dator.

3. BLE-protokollet vi reverse-engineerade

Värmaren annonserar som Heater5905 (öppen, ingen pairing). Allt styrs med 7-byte ramar till skriv-karakteristiken; status kommer som notiser:

ba ab 04 <cmd> <arg> 00 00 <checksum>

checksum = (summan av alla föregående byte) & 0xFF
KommandoBetydelseVad vi lärde oss live
0xA0StatusfrågaSvarar med ~20-byte statusram (temp, spänning, läge, nivå)
0xA1På/av-togglaVäxlar driftläge
0xA2 / 0xA3Nivå +1 / −1Så stegar appen brännarnivån — inte absolutvärden
0xDB <v>Lagra mål-värdeSätter bara målet — växlar inte läge
0xADAktivera temperatur-lägeSkickas efter 0xDB 8–36
0xACAktivera nivå-lägePraktisk nivåstyrning görs med 0xA2/0xA3
Tre fällor som kostade oss mest tid:
1. Ramar utan checksumma ignoreras tyst — inget fel, inget svar, ingenting.
2. Lägeskommandona 0xAC och 0xAD är lätta att förväxla — bevisa med råa statusramar.
3. Läget växlar inte av 0xDB ensamt: rätt sekvens är 0xDB <värde> → paus → 0xAD.

Statusramen vi parse:ar: byte 5 = läge (0 = nivå, 1 = temperatur), byte 6 = aktuell modulering, byte 7 = satt värde/mål, byte 8 = auto-flagga — plus innetemp, värmartemp och batterispänning längre fram i ramen.

4. Firmwarens byggstenar

BLE-klienten

  • Skanna → matcha namn → connect → MTU 185 → prenumerera notiser.
  • Auto-återanslut i egen FreeRTOS-task, kommandon köas som text (hex-ramar separerade med ;).
  • Max sändningseffekt: esp_ble_tx_power_set(ESP_BLE_PWR_TYPE_ADV, ESP_PWR_LVL_P20) — standard är +9 dBm men chipet klarar +20. Det var det som fick kopplingen att sitta på >25 m avstånd.

Webb-API (ESPAsyncWebServer)

EndpointFunktion
GET /api/statusJSON: temp, volt, läge, mål, fw-version, heap, RSSI
POST /api/powerStarta/stänga (togglar)
POST /api/temp0xDB v → 800 ms paus → 0xAD (värmaren hinner annars inte)
POST /api/levelStega nivå med 0xA2/0xA3 till önskad nivå
GET/POST /api/schedulesScheman: veckodags-bitmask, on/off i minuter, off<on = över midnatt
POST /api/ble-releaseApp-fönster: koppla ifrån N minuter (1–120)
/updateOTA-upload med lösenord
  • Lösenord via ?pwd= + session — och Cache-Control: no-store på allt, annars fastnar webbläsaren på gamla sidor (klassisk fälla).

Schemamotorn

  • NTP (configTime + svensk tidszon) → exakt-minut-tick.
  • Matchar veckodag + tid mot schemana i Preferences (flashminne).
  • Startsekvens: på → vänta 800 ms → läge → vänta 800 ms → temperatur — snabba kommandon i följd tappas av värmaren.

MQTT-molnet

  • PubSubClient med setBufferSize(512) — standard 256 räcker inte för status-JSON, publiceringen dör tyst.
  • Status var 5:e sekund på <topic>/status (retained); kommandon på <topic>/cmd med lösenord i varje meddelande.
  • Schemaläggning fungerar även via molnet: sched_get/add/del på cmd-ämnet, svar på <topic>/sched.

OTA

  • Lösenordsskyddad uppladdning av .bin direkt från webbsidan; kortet startar om självt.
  • Fw-version i status-JSON gör att man ser att en uppdatering tagit.

5. Webbsidorna

  • Panelen hemma bygger på kortets egen server — mörk card-layout, temp-/nivåväljare, schemasektion, OTA-ruta.
  • Molnpanelen ligger på GitHub Pages (statisk HTML + mqtt.js över WebSocket) och prenumererar på status + scheman, publicerar kommandon. GitHub Pages är publikt — därför: aldrig lösenord eller IP:er i sidkoden, och aldrig inbyggda firmware-binärer i repot (de innehåller lösenords-strängar!).

6. Så satte vi upp allt — steg för steg

  1. Reverse-engineera BLE med Python + bleak mot värmaren: hitta skriv-/notiser-karakteristiker, toggla på/av, jämför statusramar. Bevisa varje kommando innan firmware skrivs.
  2. BLE-klient + status i firmware först — "läs temp på webbsidan" är milstolpe 1.
  3. Styrning — power, temp (med pauser!), nivå. Testa varje kommando via ett rått debug-endpoint (/api/raw) utan att OTA:a om och om igen.
  4. Scheman i flashminne + NTP-klocka. Skapa ett testschema 2 minuter fram i tiden och bevaka att det startar på exakta minuten.
  5. OTA så tidigt som möjligt — allt efter det uppdateras trådlöst.
  6. MQTT + molnpanel på GitHub Pages. Testa kedjan med en minimalistisk MQTT-klient (raw sockets räcker).
  7. Placering: kortet 1–2 m från värmaren, fritt i luften, inte mot metallhöljet. Med +20 dBm satt sitter kopplingen ändå på betydligt längre avstånd.

7. Säkerhet

Värmaren bränner. Testa alltid med uppsikt, ha en fysisk avbrytargång, och behåll appen som reservväg ("släpp Bluetooth"-funktionen gör den kompatibel). Schemalagd uppvärmning av rymden du inte kan övervaka = din egen riskbedömning.
  • Lösenord på alla styr-endpoints, aldrig hemligheter i publika filer/binärer.
  • Unika MQTT-ämnen + lösenord i varje kommando — behandla publik broker som avlyssnad.
  • HTTPS på molnsidorna (GitHub Pages ger det gratis).
