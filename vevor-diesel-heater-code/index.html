Vevor Diesel Heater — firmware för ESP32-S3

Komplett källkod för fjärrstyrning av Bluetooth-utrustade dieselvärmare. Framtagen och verifierad mot en riktig Vevor Heater5905.

Översikt

Firmwaren gör en ESP32-S3 till en permanent styrcentral för värmaren: kortet äger Bluetooth-kopplingen, exponerar ett lösenordsskyddat webb-API i det lokala nätverket, kör veckoscheman med exakt minuterlighet och rapporterar status till ett valfritt MQTT-moln. Den ursprungliga mobilappen kan fortfarande användas via en släppfunktion som ger appen ensam åtkomst under vald tid.

Funktioner

  • BLE-klient mot Vevor Heater5905 — fullständig implementation av ABBA-protokollet med checksummor och förstärkt sändning (+20 dBm)
  • Webb-API — status, start/stopp, temperaturinställning 8–36 °C, effektnivå 1–10
  • Schemaläggning — 8 scheman med veckodagar och över-midnatt-fönster, lagras i flashminne och överlever strömavbrott
  • MQTT-integration — status var femte sekund, fjärrkommandon och fjärrschemaläggning
  • Appkompatibilitet — styrbar frigivning av Bluetooth-anslutningen till originalappen
  • OTA-uppdatering — lösenordsskyddad trådlös uppdatering direkt från webbsidan

Vevor Diesel Heater — firmware for ESP32-S3

Complete source code for remote control of Bluetooth-equipped diesel heaters. Developed and verified against a real Vevor Heater5905.

Overview

The firmware turns an ESP32-S3 into a permanent control hub for the heater: the board owns the Bluetooth connection, exposes a password-protected web API on the local network, runs weekly schedules with exact minute accuracy and reports status to any MQTT broker. The original mobile app can still be used through a release function that gives the app exclusive access for a chosen period of time.

Features

  • BLE client for the Vevor Heater5905 — full implementation of the ABBA protocol with checksums and boosted transmission (+20 dBm)
  • Web API — status, start/stop, temperature setting 8–36 °C, power level 1–10
  • Scheduling — 8 schedules with weekdays and over-midnight windows, stored in flash memory and resistant to power outages
  • MQTT integration — status every five seconds, remote commands and remote scheduling
  • App compatibility — controlled release of the Bluetooth connection to the original app
  • OTA updates — password-protected wireless updates directly from the web page
