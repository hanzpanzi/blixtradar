Vad du får

  • varmare.ino — komplett firmware (~1100 rader):
  • ✅ BLE-klient mot Vevor "Heater5905" (ABBA-protokollet, checksummor, +20 dBm)
  • ✅ Webb-API: status, start/stopp, temperatur 8–36 °C, nivå 1–10
  • ✅ Schemaläggning: 8 scheman, veckodagar, över-midnatt-fönster, sparas i flashminne
  • ✅ MQTT-moln: status var 5:e s + kommandon + schemaläggning via molnet
  • ✅ "Släpp Bluetooth"-fönster så mobilappen kan användas
  • ✅ Lösenordsskyddad OTA-uppdatering från webbsidan

Så använder du koden

  1. Hämta varmare.ino (knappen ovan) och lägg den i en mapp som heter varmare.
  2. Ändra överst i filen: WIFI_SSID, WIFI_PASSWORD, WEB_PASSWORD och MQTT_TOPIC (välj ett unikt ämne!).
  3. Programmera via USB (ESP32-S3 Dev Module), öppna serie-monitor och notera IP-adressen.
  4. Klart — följ bygg-sidan för moln och scheman.
